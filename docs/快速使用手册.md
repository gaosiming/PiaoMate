# 票小秘 快速使用手册

双击 `PiaoMate.exe` 即可运行，无需安装（Windows 10/11）。

## 使用步骤

1. **选发票目录**：点「浏览…」选择存放发票 PDF 的文件夹（也可直接粘贴路径），自动扫描并列出。
2. **选导出目录**：用于存放导出结果。
3. **筛选**（可选）
   - 开票日期：勾选后设置起止日期。
   - 公司抬头：不筛选 / 备选公司 / 自定义（选自定义才可填写公司名、税号）。
4. **凑金额**：输入目标总金额，点「匹配最接近的发票」。
   规则：所选合计**不少于**目标，且尽量接近。也可手动勾选微调，底部状态栏显示已选合计和与目标的差额。
5. **导出**：点「导出所选并打开目录」。发票被**移动**到「导出目录\日期时间\」，文件名末尾追加金额，并生成 `清单.txt`（文件名、抬头、税号、金额、总计）。

## 整理 / 下载发票（顶部工具栏）

- **整理发票**：扫描目录 → 「开始整理（复制）」→ 按 `抬头_税号\` 分文件夹，文件名 `金额_抬头_税号_发票号_开票日期.pdf`，默认存到 `导出目录\发票整理`。原文件不动；核对后可点「删除原始文件…」（只删已有一致副本的，移入回收站）。
- **下载发票**：粘贴链接点「下载链接」，或 Ctrl+V 粘贴二维码截图 / 图片链接，或拖入图片、PDF。下载后自动整理（诺诺网、百望云的链接可直接取得 PDF）。无法自动下载的会提示，点「在浏览器打开所选」手动下载后拖入窗口即可。
- **扫码开票**：二维码打开的是开票申请页（状态「需开票」）时，软件用内置浏览器打开，选择抬头后自动填写抬头、税号、手机、邮箱（黄色），提交按钮红框标出——**核对后由你自己点提交**，生成的 PDF 自动保存整理。

## 常用操作

| 操作 | 方法 |
|---|---|
| 排序 | 点列头 |
| 打开发票 | 双击该行 |
| 复制文件地址 | 右键 →「复制文件地址」（可多选） |
| 打开所在目录 | 右键 →「打开所在目录并选中」（可多选） |
| 查看发票概要 | 鼠标悬停在该行上（金额、抬头、税号、发票号、日期、文件路径等） |
| 刷新目录 | 点「扫描/刷新」 |
| 全选 / 清空 | 对应按钮 |
| 查看各版本改动 | 顶部工具栏右侧「更新日志」（发布包里也附有 `更新日志.md`） |

## 注意

- 灰色行 = 无法识别的 PDF（原因见该行状态），不参与匹配。扫描件/图片发票无法识别。
- 匹配和导出只针对**当前显示**的发票，先筛选再匹配。
- 导出是移动文件，重要发票请先备份。
- 设置关闭时自动保存在 exe 同目录的 `PiaoMate.config`；升级时把它复制到新版本旁即可保留设置。
- 备选公司在该文件中修改，格式：`Company1=公司名称|税号`，可按序号新增。开源版默认没有备选公司，内部版已内置。
