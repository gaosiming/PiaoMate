# 票小秘 使用说明

票小秘用来在一堆电子发票 PDF 里，**快速凑出指定金额**的发票，并整理导出给财务核对；还可以**按抬头分类整理发票**、**通过链接/二维码下载发票**（主窗口顶部工具栏）。绿色免安装，双击 `PiaoMate.exe` 即可使用。

- 运行环境：Windows 10 / 11（无需安装其他运行库）
- 支持的发票：带文字的电子发票 PDF（全电发票等）。纯图片/扫描件无法识别。

---

## 一、30 秒上手

1. 双击 `PiaoMate.exe`。
2. 点「发票目录」旁的 **浏览…**，选择存放发票 PDF 的文件夹，软件自动扫描并列出所有发票。
3. 在「导出目录」选一个用来存放结果的文件夹。
4. （可选）用「筛选」限定开票日期、公司抬头。
5. 在「目标总金额」输入需要的金额，点 **匹配最接近的发票**，软件自动勾选一组发票。
6. 点右下角 **导出所选并打开目录**，发票被整理到新文件夹，并附带 `清单.txt`。

## 二、界面说明

### 1. 目录区
| 项目 | 说明 |
|---|---|
| 发票目录 | 存放发票 PDF 的文件夹。可直接粘贴/输入路径，也可点「浏览…」。选择后自动扫描 |
| 扫描/刷新 | 重新读取目录（往目录里新增或删除了发票后点一下）。已勾选的发票刷新后保持勾选 |
| 含子文件夹 | 勾选后连同子文件夹里的 PDF 一起读取 |
| 导出目录 | 导出结果存放的位置 |

「浏览…」打开的是带地址栏的文件夹选择框：可以直接在地址栏粘贴路径后回车。

### 2. 筛选区（两行）
**第一行：开票日期**
勾选「开票日期」后，设置起止日期，列表只显示该时间范围内（含起止当天）的发票。

**第二行：公司抬头**（按发票的「购买方」筛选）

| 下拉选项 | 效果 | 右侧「公司名称 / 税号」框 |
|---|---|---|
| 不筛选（全部） | 显示所有发票 | 空，不可编辑 |
| 备选公司 | 只显示该公司抬头的发票（税号或名称一致即可） | 显示该公司名称与税号，不可编辑 |
| 自定义… | 按你填写的名称和/或税号筛选 | 可编辑 |

自定义规则：
- 只填税号：税号完全一致的发票。
- 只填公司名：购买方名称**包含**该文字的发票。
- 两个都填：两者都要满足。
- 两个都留空：不筛选。

> 备选公司可在配置文件里修改或新增，见「五、配置文件」。

### 3. 凑金额区
- **目标总金额(元)**：输入需要凑的金额，如 `1234.56`。
- **匹配最接近的发票**（也可在输入框按回车）：自动勾选一组发票。
- **全选 / 清空选择**：对当前显示的发票批量勾选或取消。

### 4. 发票列表
| 列 | 内容 |
|---|---|
| 开票日期 | 发票开具日期 |
| 公司抬头(购买方) | 发票上的购买方名称 |
| 税号 | 购买方纳税人识别号 |
| 项目名称 | 发票明细项目，多项用「；」分隔 |
| 价税合计 | 发票最终金额（含税） |
| 文件名 / 状态 | PDF 文件名；识别失败的会显示原因 |

操作技巧：
- 单击列头可按该列排序，再点一次反向。
- 勾选每行左侧的方框即选中该发票，也可手动微调自动匹配的结果。
- **双击**某一行：用默认 PDF 阅读器打开这张发票。
- **右键**某一行 →「复制文件地址」：把该发票文件的完整路径复制到剪贴板。先选中多行再右键，可一次复制多个，每个路径占一行。
- **右键** →「打开所在目录并选中」：在资源管理器中打开发票所在文件夹并选中该文件（多选时同一文件夹的会一起选中）。「整理发票」窗口中还可分别打开原文件或整理后文件的位置。
- **鼠标悬停**在某一行上：显示发票概要——金额、抬头、税号、发票号码、开票日期、销售方、项目、文件路径（整理窗口还显示整理后位置和状态）。
- 灰色行表示无法识别的 PDF（见「六、常见问题」），不参与筛选和匹配，但仍可右键复制其地址。
- 表格或窗口内容放不下时，可以水平/垂直滚动。

### 5. 底部状态栏
实时显示：当前显示的发票数 / 总数、已选张数、已选合计金额，以及（已填目标金额时）**与目标相差多少**。

## 三、凑金额的规则

**所选发票合计 ≥ 目标金额，并且尽可能接近目标金额。** 也就是发票只会多、不会少（给足），并且多出的部分尽量小，以减少浪费。

- 恰好能凑齐时，合计就等于目标金额。
- 匹配只在**当前显示的发票**里进行，所以要先用筛选限定范围（例如某个公司、某个月份），再匹配。
- 如果显示的全部发票加起来也不够，会弹窗提示合计与差额，且不会勾选任何发票。
- 金额为 0 或负数（如红字发票）的发票不参与自动匹配。
- 自动匹配后，你仍可手动勾选/取消，状态栏会实时显示与目标的差额。

## 四、导出

点 **导出所选并打开目录**：

1. 软件列出将导出的张数和合计，确认后继续。
2. 在导出目录下新建一个以日期时间命名的子文件夹，例如 `20261117_143005`。
3. 把所选发票**移动**到这个子文件夹（注意是移动，不是复制，原目录里不再保留）。
4. 文件名末尾自动追加发票金额，方便比对，例如：
   `北京某公司_发票.pdf` → `北京某公司_发票_34.92.pdf`
   如果原文件名里已经包含该金额，则不重复追加。
5. 同时生成 `清单.txt`（用记事本打开即可），内容示例：

   ```
   发票清单    导出时间：2026-11-17 14:30:05
   ============================================================
   1. 文件名：26110000000000000001_某公司_34.92.pdf
      抬头：示例科技有限公司    税号：91110000MA00000001    金额：34.92 元

   2. 文件名：26110000000000000002_33.08_某公司.pdf
      抬头：示例（北京）贸易有限公司    税号：91110000MA00000002    金额：33.08 元

   ============================================================
   共 2 张    总计金额：68.00 元
   ```
6. 自动打开该子文件夹。已导出的发票会从列表中消失。

> 只会导出「当前显示」且已勾选的发票；被筛选条件隐藏的发票即使之前勾选过，也不会导出。

## 五、整理发票（工具栏「整理发票」）

把一个目录里杂乱的发票，按**抬头 + 税号**分类归档，便于后续查找。

1. 点主窗口顶部工具栏的 **整理发票**。
2. 「发票目录」默认为主窗口的发票目录，可另选；点 **扫描**。
3. 「整理到」默认为 `导出目录\发票整理`，可另选（会记住）。列表最后一列预览整理后的位置。
4. 勾选要整理的发票，点 **开始整理（复制）**。

整理结果：

```
发票整理\
  示例科技有限公司_91110000MA00000001\
    34.92_示例科技有限公司_91110000MA00000001_26110000000000000001_20260827.pdf
    清单.txt
  示例（北京）贸易有限公司_91110000MA00000002\
    33.08_示例（北京）贸易有限公司_91110000MA00000002_26110000000000000002_20261111.pdf
```

- 文件名：`金额_抬头_税号_发票号_开票日期.pdf`，日期为 8 位年月日（如 `20260827`）；没有税号的（如个人抬头）省略税号，读不到发票号或日期的省略该项。文件名以金额开头，在文件夹中按名称排序即可大致按金额查找。
- 重名但内容不同的发票自动加序号 `(2)`；**完全相同**的发票（如重复下载）只保留一份。
- 每个分类文件夹里的 `清单.txt` 记录整理时间、发票号码和原文件位置。
- 「整理到」目录本身不会被重复扫描；无法识别的 PDF 不参与整理。

**删除原始文件（谨慎）**：整理只**复制**，原文件保持不动。确认整理结果无误后，可点 **删除原始文件…**：
- 只删除「整理目录中已有内容完全一致副本」的原文件（逐个比对文件内容）；整理后被改动过的原文件不会删除。
- 删除前会列出将删除的文件，默认按钮为「否」；删除的文件**移入回收站**，可从回收站恢复。

## 六、下载发票（工具栏「下载发票」）

通过链接或二维码下载发票 PDF，下载后**自动按「五」的规则整理**到「整理到」目录。

| 方式 | 操作 |
|---|---|
| 发票链接 | 粘贴到输入框（每行一个），点 **下载链接** |
| 二维码截图 | 截图后在窗口内按 **Ctrl+V**（或点「粘贴二维码/链接」） |
| 二维码图片文件 | 点「选择二维码图片…」，或直接把图片拖入窗口 |
| 图片链接 | 粘贴图片网址，软件会下载图片并识别其中的二维码 |
| 已手动下载的 PDF | 点「导入已下载的 PDF…」或拖入窗口（原文件保留） |

**已适配的开票平台**（直接调用平台接口取得 PDF，无需打开网页）：

| 平台 | 链接示例 | 说明 |
|---|---|---|
| 诺诺网 | `https://nnfp.jss.com.cn/xxxx`（短链或扫码链接） | 已开具的发票自动下载 PDF；需要验证码、验证购方名称或尚未开具完成的，会提示并可在内置浏览器中继续 |
| 百望云 | `https://pis.baiwang.com/smkp-vue/previewInvoice…?param=…`（扫码开票页，含微信卡包跳转的链接） | 已开具的发票自动下载 PDF；链接无效、已失效或需先同意授权的，会提示并可在内置浏览器中继续 |

其他平台按通用方式尝试（跟随跳转、在页面中查找 PDF 链接）。如果提示「该开票平台（某域名）尚未专门适配」，可以把链接（建议用已开具、不介意他人看到的发票）发给开发者逐个适配。

已整理的行可**右键 →「打开所在目录并选中」**（定位到整理后的发票文件）或「复制文件地址」；**鼠标悬停**显示来源、状态和发票概要（金额、抬头、税号、发票号码、日期、整理后路径），未成功的行悬停可看到完整提示和链接。

加错的项可选中后点 **删除所选**（或按 Delete 键、右键菜单），点 **清空列表** 移除全部；只移除列表中的记录，不会删除已下载/整理的文件，正在处理中的一项需等其完成后再删。

软件会自动跟随跳转、在页面中查找 PDF 下载地址。列表「状态」说明：

- **已整理**：已下载并整理，「结果」列为整理后的文件，双击可打开。
- **已整理(未识别)**：下载到的 PDF 不是可识别的发票，放在 `整理目录\_未识别\`，请人工确认。
- **需手动下载**：无法自动下载（页面需要点击、输入验证码、需在微信/支付宝中打开，或只提供 OFD 格式等）。选中该行点 **在浏览器打开所选**（或双击）手动下载，下载后把 PDF 拖入本窗口即可自动整理。
- **需开票**：扫码后打开的是开票申请页面（需要填写抬头、税号、手机号、邮箱等）。见下方「扫码开票」。
- 如果二维码是发票上的**查验二维码**（内容形如 `01,32,,发票号码,金额,日期,…`），其中不含下载地址，软件会显示发票号码/金额/日期，需向开票方索取或到电子税务局下载。

### 扫码开票（内置浏览器）

餐厅小票等「扫码开票」的二维码，扫码后通常要先填写开票信息、提交后才能拿到发票。软件可以帮你自动填写：

1. 粘贴二维码后，若识别为开票页面，该行状态为「需开票」，并自动打开内置浏览器（批量添加时请双击该行，或点「内置浏览器开票」）。
2. 在弹出的窗口中**选择开票抬头**，确认手机号、邮箱（会记住，下次自动带出）。
3. 内置浏览器打开开票页面后：
   - 有「个人 / 企业」切换的，自动选「企业」；
   - 自动填写抬头、税号、手机号、邮箱，已填写的输入框显示为**黄色**；地址、验证码、备注等不会填写，已有内容的框也不会被覆盖；
   - 提交/开票按钮用**红框**标出。
4. **请核对信息无误后，自己点击红框按钮提交开票**——软件不会替你提交，避免开错抬头。
5. 提交后，页面中出现的发票 PDF（下载、预览或下载链接）会被自动保存并按「五」的规则整理，结果显示在窗口底部和下载列表中。

其他说明：
- 窗口顶部可随时切换抬头或修改手机号、邮箱，点「重新填写」覆盖页面中的内容；取消「自动填写」可停止自动填写。
- 要求在微信/支付宝中打开、需要短信/图形验证码（需手动输入）、或只发送到邮箱的开票方式，无法全自动完成；可点「用系统浏览器打开」或用手机操作。
- 内置浏览器使用 Windows 自带的 Microsoft Edge WebView2（Win10/11 一般已安装；未安装时会提示）。浏览数据保存在 `%LOCALAPPDATA%\PiaoMate\`。

## 七、配置文件（设置自动保存）

软件关闭时自动保存当前设置，下次启动自动恢复：发票目录、导出目录、整理目录、是否含子文件夹、日期范围、公司抬头选择、自定义内容、目标金额、窗口大小。

- 配置保存在 `PiaoMate.exe` 同目录下的 **`PiaoMate.config`**（文本文件，可用记事本编辑）。如果该目录不可写，则保存到 `%APPDATA%\PiaoMate\`。
- **升级新版本**：把旧版本目录里的 `PiaoMate.config` 复制到新版本的 exe 旁边即可保留设置。
- **恢复默认设置**：关闭软件，删除 `PiaoMate.config`。
- 移动软件位置时，连同 `.config` 一起拷贝。

### 修改或新增备选公司
关闭软件后，用记事本打开 `PiaoMate.config`，找到：

```
Company1=示例科技有限公司|91110000MA00000001
Company2=示例（北京）贸易有限公司|91110000MA00000002
```

格式为 `CompanyN=公司名称|纳税人识别号`。可直接修改，也可以按序号新增（`Company3=…`、`Company4=…`），保存后重新打开软件，下拉框里就会出现。

> 开源（公开）版默认没有备选公司，首次使用请按上面的格式添加，或在筛选区选「自定义…」填写公司名称和税号。公司内部版（标题栏带「内部版」）已内置本公司的备选公司。

## 八、常见问题

**Q：有的发票显示为灰色「无法识别」？**
看该行「文件名 / 状态」列里的原因：
- 「PDF 中没有可提取的文字（可能是扫描件/图片）」：图片型发票，目前无法识别，需手动处理。
- 「未识别到价税合计金额（可能不是发票）」：该 PDF 不是标准电子发票，或版式特殊。
- 其他读取错误：文件可能损坏或有密码保护。

如果你确认是正常的电子发票却识别失败，请把该文件（建议脱敏）和状态文字反馈给开发者。

**Q：列表里某张发票的开票日期是空的？**
个别发票读不到日期但能读到金额，会照常列出。开启「开票日期」筛选时，这类发票会被排除。

**Q：自动匹配结果比目标多了一点，能刚好等于吗？**
软件已在所有组合中选了「不少于目标且最接近」的一组。如果多出一点，说明现有发票凑不出更接近的组合。

**Q：导出后发现选错了怎么办？**
导出是移动文件，可到导出的子文件夹里把发票手动拖回原目录，再点「扫描/刷新」。建议重要发票先备份。

**Q：杀毒软件提示/运行不起来？**
软件是单文件便携程序，未经商业签名，个别安全软件可能提示未知程序，选择信任/允许即可。

**Q：窗口显示不全？**
窗口较小时，主界面可滚动、筛选区自动换行，表格可水平/垂直滚动；也可以拖动窗口边缘或最大化。

## 九、使用小贴士：尽量不浪费发票

1. 先按「公司抬头」「开票日期」筛选，把范围缩到本次报销允许的发票。
2. 输入目标金额匹配，查看状态栏的「与目标相差」。
3. 想换一批组合时，注意「匹配」每次都会重新选择，不会保留手动勾选；可以把不想用的发票临时移出发票目录再点「扫描/刷新」，或用日期/抬头筛选把它们排除，然后重新匹配。
4. 导出后用 `清单.txt` 与财务核对：张数、每张金额和总计。
